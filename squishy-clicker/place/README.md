# The place file

Since the world went **baked**, the place file is real content, not a build
product: it holds the hand-edited map, every hand-imported model
(cannon, capsules, squishy meshes, the Meshy trio) and the Lighting setup.
Losing it would mean redoing all of that by hand — so a snapshot belongs in
the repo.

To update the snapshot from Studio:

1. **File → Save to File As…**
2. Save as `SquishyLauncher.rbxl` **in this folder**.
3. Commit and push (or ask Claude to).

The live game stays wherever you publish it on Roblox; this is the backup
and the version history.
